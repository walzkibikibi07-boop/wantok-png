Build the WANTOK PNG Android MVP in this repository. First create a new branch named wantok-png-mvp. Do not modify the main/default branch. Use Kotlin, Jetpack Compose and MVVM. Create the Android project files and implement the MVP screens: Home, Marketplace, Jobs, Services, Communities, Events, Help, Profile, Notifications and Settings. Add GitHub Actions for an Android debug APK build. Implement the files, build/test the project, fix errors, and create a pull request when finished.
